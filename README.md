# Intro to Python

Course notebooks for **Intro to Python**.

## Getting started

Clone the repository:

```bash
git clone https://github.com/ankurdivekar/python-course.git
cd python-course
```

Set up the environment (requires [uv](https://docs.astral.sh/uv/)):

```bash
uv sync
uv run jupyter lab
```

## Updates

This repository is updated automatically as new material is released. Run `git pull` regularly to get the latest notebooks.
